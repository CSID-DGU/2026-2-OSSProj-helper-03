# Src

Helper의 소스 코드를 두는 폴더입니다. 지금은 기술 검증 단계라 코드가 아직 없고, 1단계 개발(7\~10주차)부터 채워 나갑니다.

## 예정 구조

```
Src/
├── engine/     음성 처리와 대본 추적 (Python)
│   ├── cue_loader      ① 큐 시트 로더
│   ├── audio_input     ② 오디오 입력, 음성 구간 검출
│   ├── stt             ③ 음성인식
│   ├── aligner         ④ 대본 정렬 엔진
│   ├── deviation       ⑤ 대본 이탈 감지
│   └── session_log     ⑦ 회차 로그
├── server/     로컬 서버 (FastAPI, WebSocket)
├── ui/         보조 화면, 준비 화면, 설정 화면 (React, Vite, TypeScript)
└── tests/      테스트 (pytest)
```

2단계의 ⑧ 송출 큐 연동과 3단계의 ⑨ 자동 전진 제어는 송출 프로그램 연동 방식을 확인한 뒤 폴더를 추가합니다.
폴더 이름은 개발하면서 바뀔 수 있고, 바뀌면 이 문서도 같이 고칩니다.

## 개발 환경

- Python 3.11
- Node.js (보조 화면 빌드용)
- 음성인식 모델은 10월 기술 검증에서 로컬(faster-whisper)과 클라우드 API를 비교한 뒤 정합니다.

설치와 실행 방법은 첫 코드가 올라올 때 이 문서에 적습니다.

## 올리지 않는 파일

- 공연 대본, 자막 큐 파일, 공연 음원: 제작사 자산이라 저장소에 올리지 않습니다. 테스트에는 공개 희곡과 직접 만든 예시 큐 파일을 씁니다.
- 음성인식 모델 파일, API 키, 가상환경 폴더
